# Support

Welcome to **Pinvault Pinterest Downloader** support. This page helps you get the most out of the Extension and resolve common issues.

## How to Use

1. Install the Extension from the Chrome Web Store.
2. Open any Pinterest board, pin, or search results page.
3. Click the Pinvault icon or use the in-page download button.
4. Choose the images / videos you want, then click **Download**.
5. Files are saved to your browser's default download folder.

## Common Issues & FAQ

**Q: Downloads don't start.**
Make sure your browser's download prompt is allowed, and that the page you are on has finished loading.

**Q: Some videos can't be downloaded.**
Pinterest occasionally restricts certain media from being saved. Try a different pin or page.

**Q: The Extension stopped working after an update.**
Refresh the Pinterest page (Ctrl+R / Cmd+R). If it persists, restart your browser.

**Q: Is my data collected?**
No. All processing happens locally on your device. See our [Privacy Policy](https://github.com/hamid-digitalmarketer/pinvault-pinterest-downloader/blob/main/docs/privacy-policy.md).

## Report a Problem

Please open an issue with the following details:
- Extension version (visible in chrome://extensions)
- Browser and OS version
- Steps to reproduce
- Screenshot or error message (if any)
